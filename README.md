🕹️ About the Game

Pixel-Boy brings the classic Snake experience back with a pixel-art-inspired interface, nostalgic green display, and virtual handheld-console controls.

Eat the fruit, grow your snake, beat your high score, and explore the entire board without worrying about walls.

That's right — the walls are portals!

When your snake leaves one edge of the screen, it reappears on the opposite side. The only thing that can end your run is colliding with your own body.

✨ Features

- Retro Arcade Design — Pixel-inspired graphics and a classic handheld-console interface.
- Wraparound Walls — Travel through one edge and emerge from the opposite edge.
- Classic Snake Gameplay — Eat fruit, grow longer, and earn points.
- Score Tracking — Earn 10 points for every fruit collected.
- Personal Best — Your best score is saved locally in your browser.
- Mobile-Friendly Controls — Use the on-screen directional pad or swipe across the game screen.
- Keyboard Support — Play with the arrow keys or WASD.
- Pause and Resume — Take a break whenever you want.
- Responsive Layout — Play on mobile phones, tablets, and desktop computers.
- Zero Dependencies — No external libraries, frameworks, or build tools.
- Single-File Architecture — The complete game lives inside one "index.html" file.

🎯 How to Play

1. Press START / RESUME to begin.
2. Move your snake toward the red fruit.
3. Collect fruit to increase your score and grow longer.
4. Pass through the walls to reach the opposite side.
5. Avoid running into your own body.
6. Beat your personal best!

🎮 Controls

Action| Control

🚀 Getting Started

Option 1 — Play Online

Visit the live game:

"▶ Play Pixel-Boy" (https://YOUR-USERNAME.github.io/retro-snake/)

Replace "YOUR-USERNAME" with your GitHub username after enabling GitHub Pages.

Option 2 — Run Locally

1. Clone this repository:
   
   git clone https://github.com/YOUR-USERNAME/retro-snake.git

2. Enter the project directory:
   
   cd retro-snake

3. Open "index.html" in your browser.

That's it! No package installation or build command is required.

🌐 Deploy with GitHub Pages

You can host Pixel-Boy for free using GitHub Pages.

1. Push "index.html" to your GitHub repository.
2. Open the repository's Settings.
3. Select Pages under the Code and automation section.
4. Under Build and deployment, select Deploy from a branch.
5. Choose the "main" branch and "/ (root)" folder.
6. Click Save.

After GitHub finishes publishing your site, open:

"https://YOUR-USERNAME.github.io/retro-snake/"
